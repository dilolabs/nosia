# MCP OAuth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-ruby:subagent-driven-development (recommended) or superpowers-ruby:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let each Nosia account member authorize and use their own OAuth grant for a shared Streamable HTTP MCP connector.

**Architecture:** Replace the vendored MCP client with RubyLLM 2.2.3's native client. Keep credentials and the OAuth protocol in RubyLLM; Nosia identifies each grant, guards all outbound requests, and supplies account-scoped workspace and chat controls. Built-in tools continue to use the official `mcp` SDK's tool types, not its client.

**Tech Stack:** Ruby 4, Rails 8.1, PostgreSQL/pgvector, Active Record encryption, RubyLLM 2.2.3, Faraday/Net::HTTP, Hotwire/Stimulus, Minitest/Selenium.

---

Approved specification: [`2026-11-19-mcp-oauth-design.md`](../specs/2026-11-19-mcp-oauth-design.md) at `e5ad1c9`. The written spec was approved before this plan. No catalog additions, pre-registered clients, shared grants, legacy SSE adapter, or native desktop browser handoff.

- [ ] Add one named `McpOutbound::Adapter < Faraday::Adapter::NetHttp` for the isolated RubyLLM context. Keep Faraday's streaming behavior and only override socket construction and result observation. Store the operation in a Ruby fiber-local, set and restored by `McpOutbound.with(scope)`. This is not ambient authentication: each workspace operation and each tool invocation sets its own scope from an explicitly scoped owner. Never alter the global RubyLLM inference adapter.

  ```ruby
  # lib/mcp_outbound/adapter.rb — connection hook called by Faraday for each attempt
  def net_http_connection(env)
    scope = McpOutbound.current!
    uri, address = McpOutbound.destination!(env.url, https_only: scope.https_only?)
    scope.admit!(env)
    Net::HTTP.new(uri.hostname, uri.port, nil).tap do |http|
      http.ipaddr = address.to_s
    end
  end

  def call(env)
    scope = McpOutbound.current!
    attempt = scope.capture(env)
    super(env).tap { |response| scope.observe(attempt, response) }
  end
  ```

  For `destination!`, parse the URI, require a host and allowed scheme, reject URL credentials and fragments, resolve `.hostname` once, normalize mapped IPv4, and reject the entire result if any address is not public. Allow IPv6 global unicast only, excluding special/documentation ranges; for IPv4 combine the existing private/loopback/link-local/CGNAT policy with reserved, multicast, benchmarking, and documentation ranges. Return the parsed URI and a validated address. Disallow Net::HTTP retries beneath this hook (Faraday's Net::HTTP adapter already sets `max_retries = 0`). Keep TLS peer and hostname verification, normal Host, and redirect refusal; stream responses via Faraday, not by reimplementing the HTTP or OAuth protocol. `capture` runs before Faraday overwrites the request body with the response; it passes no raw secrets to `observe`. Static `McpOutbound::Scope` supplies no-op `admit!`, `capture`, and `observe`; `McpOutbound.current!` fails closed if the scope is absent.
